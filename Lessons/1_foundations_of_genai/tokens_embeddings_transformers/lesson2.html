Foundations: Lesson 2 - Embeddings: Meaning in Vector Space

Lesson 1 turned text into token IDs — arbitrary integers with no built-in notion of similarity. This lesson covers embeddings: learned vectors that place related tokens near each other in a high-dimensional space. That geometry is what makes analogies, search, and (later) contextual meaning possible.

1. The Problem: Token IDs Are Arbitrary

Token ID 5000 and token ID 5001 are just consecutive integers. To the model's lookup table, they are unrelated symbols — like library shelf numbers that happen to be adjacent.

  • "king" and "queen" are semantically close (royalty), but their IDs might be 5000 and 8721.
  • "king" and "king" must always map to the same vector — IDs are stable.
  • Nothing in the integer itself encodes gender, sentiment, or topic.

We need a second step: turn each token ID into a dense vector where proximity reflects meaning.

2. Embeddings: Converting Tokens to Vectors

An embedding is a learned mapping: token ID → vector of real numbers. GPT-2 uses 768 dimensions per token; larger models use 4,096 or more.

Token ID 5000 → Embedding matrix lookup → Vector [0.2, -0.5, 0.8, …]
Token IDTokenEmbedding (first 5 dims, illustrative)
5000king[0.82, 0.61, 0.15, 0.44, -0.08]
8721queen[0.74, 0.59, -0.12, 0.41, -0.06]
1203apple[-0.55, -0.48, 0.05, -0.33, 0.22]

Vectors are not hand-coded. They are rows of an embedding matrix updated during training. Each dimension is not guaranteed to mean one human-readable feature (like "gender"), but the full vector encodes statistical regularities from context.

Intuition: tokens that appear in similar contexts end up with similar vectors.

3. The Embedding Space (Vector Space)

Picture a space where every token is a point. In 2D (for teaching), we might plot:

queen(0.7, 0.6)king, throne, crown

Meaning ≈ proximity. Real models use hundreds or thousands of dimensions; we project to 2D only for visualization.

4. Analogies in Vector Space

The famous relation: king − man + woman ≈ queen

Vector differences can encode relationships. If the "gender" direction is similar between (king→queen) and (man→woman), arithmetic recovers the right neighbor.

Other analogies (when training data supports them):

  • Paris − France + Germany ≈ Berlin
  • programmer − Python + Java ≈ developer (approximate)

Analogies are approximate — they work when the relationship direction is consistent in embedding space.

5. How Embeddings Are Learned

  1. Initialize random vectors for every token in the vocabulary.
  2. Train the model to predict the next token (or masked tokens).
  3. Backpropagation updates embedding rows along with other weights.
  4. After billions of updates, tokens in similar contexts cluster; related meanings align.

No human labels "royalty" or "gender." Structure emerges from the prediction objective.

7. Contextualized Embeddings (Preview)

Problem: static embeddings assign one vector per token type. But "bank" in "river bank" ≠ "bank" in "Bank of America."

Transformers fix this: the same token ID starts from the same lookup vector, but layers of attention produce context-dependent representations. Lesson 3 covers the architecture; here we preview the idea.

SentenceAfter transformer (conceptual)
I went to the bank to withdraw money."bank" vector shifts toward finance cluster
I sat on the bank of the river."bank" vector shifts toward nature/geography cluster

Check Your Knowledge: Static vs Contextual

Question: A model uses only a fixed embedding lookup with no transformer layers. Can it represent both meanings of "bank" simultaneously at one position?

Click to reveal answer

No — one token ID → one static vector. Contextual models combine the lookup with surrounding tokens via attention to produce different final vectors.

9. Activities

  1. Nearest neighbors: Search a token. List 5 neighbors. Do they make semantic sense?
  2. Analogy test: Run king − man + woman. Is the top result queen? Try a custom analogy.
  3. Surprising non-neighbors: Find two words you expect to be similar but are far apart — what might training data explain?
  4. Isolated token: Which token is farthest from the cluster center? Why?
  5. Context: Compare "bank" in both sentences. How far apart are the contextual vectors?

Check Your Knowledge: Embeddings

Question: Cosine similarity between "doctor" and "nurse" is 0.72; between "doctor" and "teacher" is 0.45. What does that suggest?

Click to reveal answer

Embeddings place doctor closer to nurse (shared healthcare context) than to teacher (education context). Similarity is graded, not binary.
