Transformers: Putting It All Together

Lessons 1–3 covered three building blocks: tokens (text split into pieces), embeddings (each token as a vector of numbers), and attention (each token weighted against every other token to gather context). This lesson shows how those pieces are wired into a complete Transformer model that predicts the next token.

Models like GPT are Transformers. At inference time they take a text prompt, run it through a fixed sequence of operations, and output a probability distribution over the vocabulary. The highest-probability token (or a sampled token) becomes the next word. That process repeats to generate longer text.

1. End-to-end data flow

A decoder-only Transformer (the type used in GPT) processes text in this order:

GPT-2 (small) uses 12 stacked Transformer blocks, a hidden size of 768, and a vocabulary of 50,257 tokens. Larger models increase layer count, hidden size, and parameter count.

2. Worked example: "The cat sat"

Here is what happens inside the model for the prompt The cat sat:

  1. Tokenization. The tokenizer splits the string into pieces and maps each to an ID. Example: ["The", " cat", " sat"] → [50, 3277, 2521]. (Exact IDs depend on the tokenizer.)
  2. Embedding lookup. Each ID indexes a row in an embedding matrix. You get one 768-dimensional vector per token. Shape: (3, 768).
  3. Positional encoding. A position vector is added to each token embedding so the model can distinguish order. Token 0 is "The", token 2 is "sat". Shape stays (3, 768).
  4. Transformer blocks. The tensor passes through 12 identical blocks in sequence. Each block applies self-attention then a feed-forward network. Shape stays (3, 768) throughout.
  5. Extract last position. For next-token prediction, only the vector at the final position matters — the slot after sat. Because of causal masking, this vector has attended to all prior tokens but not future ones.
  6. Logits. The last vector is multiplied by an output weight matrix to produce one raw score (logit) per vocabulary token: shape (50257,).
  7. Softmax. Logits are converted to probabilities. Example: " on" = 52%, " down" = 14%, etc.
  8. Sample or argmax. The model selects the next token. If it picks on, the sequence becomes The cat sat on and the loop restarts from step 1.

3. Inside one Transformer block

Each block runs the same sub-operations. Data shape is unchanged: (sequence_length, hidden_size) in, same shape out.

OrderComponentWhat it computes
1Multi-head self-attentionEach token builds a new representation by taking a weighted sum of all previous tokens (causal mask blocks future positions). Multiple heads run in parallel with separate Q/K/V projections.
2Add & LayerNormResidual connection: add the block input to the attention output, then normalize. Preserves gradient flow during training.
3Feed-forward network (MLP)Two linear layers with a nonlinearity: 768 → 3072 → 768. Applied independently to each token position.
4Add & LayerNormSecond residual connection and normalization before passing to the next block.

Research on trained models shows that early layers often encode syntax and local structure; later layers encode broader semantic relationships. You do not need to assign meaning to individual layers to use the architecture — this is an observed property of trained networks.

4. Autoregressive generation

GPT-style models are autoregressive: they generate one token at a time and append each new token to the input before predicting the next one.

During training and inference, a causal mask prevents position i from attending to positions j > i. That enforces left-to-right generation — the model cannot use future tokens to predict the present one.

StepInput to modelPredicted token
1The cat saton
2The cat sat onthe
3The cat sat on themat

Generation stops when the model outputs an end-of-sequence token or hits a length limit.

5. Transformers vs. RNNs

PropertyRNN / LSTMTransformer

Long-range dependenciesInformation passes step-by-step; distant tokens are harder to linkAny token can attend to any prior token in O(1) attention hops per layer
Training cost vs. lengthO(n) per layerO(n²) for attention over sequence length n
ScalingPerformance plateaued with sizeLoss continues to improve predictably with more parameters and data (scaling laws)

6. Practical limits

  • Context window. Attention is computed over a fixed maximum number of tokens. Tokens outside the window are not visible to the model.
  • Quadratic attention cost. Doubling sequence length roughly quadruples attention compute and memory.
  • Next-token objective. The model is trained to predict likely continuations, not to verify facts. Incorrect but fluent text (hallucinations) can still have high probability.

Causal masking ensures position i only attends to positions ≤ i. The last position has attended to every token in the prompt, so its vector is the model's full-context representation for next-token prediction.
