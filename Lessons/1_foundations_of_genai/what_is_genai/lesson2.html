Foundations: Lesson 2 - Generative vs Discriminative

Lesson 1 defined generative AI as sampling new content from a learned data distribution. This lesson formalizes the distinction between discriminative models that predict labels from inputs and generative models that model the data itself.

1. Discriminative Models

A discriminative model estimates the conditional probability of a label given observed data. It learns decision boundaries that separate classes or regression surfaces that map features to scalars.

Training uses labeled pairs (x, y). At inference, the model outputs one label or one number per input.

TaskInputOutput
Spam detectionEmail textspam or not spam
House price regressionSize, location, agePrice in dollars
Digit classification16×16 grayscale imageInteger 0–9

Objectives include cross-entropy for classification and MSE for regression — the same loss functions from the prerequisites unit.

Check Your Knowledge: Discriminative Output

Question: A model maps a 28×28 MNIST image to one of ten digit classes. How many distinct output values can it return per image?

Click to reveal answer

Ten (digits 0–9). Discriminative classification restricts output to a fixed label set; it does not generate new pixel arrays.

2. Generative Models

A generative model estimates the probability distribution of data P(x) or a conditional distribution P(x | c) given context c. It samples new instances from that distribution.

Training uses unlabeled or weakly labeled corpora. At inference, each sample can differ even when the prompt is identical.

Text generationPrompt stringNew token sequence
Image generationText descriptionNew image (pixel array)

Check Your Knowledge: Generative Variability

Question: You run the same prompt through a text generator five times and get five different paragraphs. Does this behavior indicate a discriminative or generative model?

Click to reveal answer

Generative. Sampling from P(x | prompt) produces stochastic outputs; a discriminative classifier returns the same argmax label for identical inputs (ignoring numerical noise).

4. Probability Objectives

Discriminative and generative models optimize different probability objects.

Discriminative: P(label | data)

The model estimates P(y | x) — the probability of each label y given input x.

Example: for iris measurements x = [sepal_length, petal_width], output might be P(setosa|x) = 0.91, P(versicolor|x) = 0.07, P(virginica|x) = 0.02. Prediction: argmax_y P(y|x).

Generative: P(data)

The model estimates P(x) — how likely an entire data instance is under the learned distribution.

Example: a language model assigns probability to each token sequence. Generation samples tokens so the joint sequence has high probability under P(x_1, x_2, ..., x_T) = prod_t P(x_t | x_1, ..., x_{t-1}).

Learning P(x) over high-dimensional spaces (images, long text) requires more parameters and data than learning P(y|x) for a small label set.

Check Your Knowledge: Probability Object

Question: A softmax classifier outputs [0.05, 0.90, 0.05] over three iris species. What probability object did it model, and what is the predicted class?

Click to reveal answer

P(y|x) — conditional class probabilities. Predicted class: index 1 (versicolor) because 0.90 is the maximum entry.

Generative mode samples flower descriptions from a fixed corpus — simulating stochastic output from P(text | prompt).
