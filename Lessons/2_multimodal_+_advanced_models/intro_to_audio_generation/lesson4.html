0. Formal objective

P(at | a1,…,at−1, c)   where c may be text embeddings, codec prefix, melody, or ∅

Condition types you will meet

  • Text — natural language prompts.
  • Audio prefix — first N codec tokens copied from a clip.
  • Classifier-free dropout — c=∅ during training for guidance at inference.
  • Symbolic — MIDI-like melody matrices (Bach Doodle).

2. Text → condition c (implementation sketch)

  1. Tokenize prompt → IDs (L,).
  2. Embed → (L, dtext) e.g. d=1024.
  3. Transformer audio blocks use cross-attention: queries from audio, keys/values from text.
  4. Alternative: prepend text tokens to audio stream (prefix LM).
"lo-fi piano" → Tokenizer → (L,) IDs → T5 encoder → (L, 1024) Audio stream a_<t: (t,) interleaved codec IDs → embed → (t, d) → layers with cross-attn to text → logits (2048,)

3. Audio continuation — prefix frame math

3 s audio prompt @ 50 Hz, K=4
  • Prefix frames: F = 3 × 50 = 150
  • Prefix tokens: 150 × 4 = 600 IDs (fixed, not resampled)
  • Generate +5 s new: ~5 × 50 × 4 = 1000 additional AR steps
  • Model computes P(a601 | a1:600, c) onward.
Quiz 2: 2.5 s prefix — frames?
Show answer

125 frames.

4. Classifier-free guidance (CFG) — brief

logitsguided = logits∅ + w · (logitsc − logits∅)

Train with random dropout of c. At inference, w>1 pushes toward prompt. Image diffusion unit derives this deeply; for AR audio, apply same linear blend on token logits before softmax.

High w can cause metallic artifacts or mode collapse — trade quality vs adherence.

8. Sampling knobs — temperature & top-p (text and audio)

After conditioning shifts logits, sampling chooses the actual next token:

  • Temperature τ: divide logits by τ before softmax. τ < 1 sharpens (safer, repetitive); τ > 1 flattens (wilder).
  • Top-p (nucleus): truncate to smallest set whose cumulative prob ≥ p, renormalize, sample.
Toy effect: If conditioned probs are 54% riff / 24% glitch / 22% others, τ=0.7 pushes riff higher still; τ=1.3 lets glitch compete — same c, different randomness.

15. Numerical lab — prefix + text together

Scenario: User uploads 3 s of drum loop and types "add jazz chords, warm piano". System encodes 3 s → prefix tokens; text → c.
  • Prefix frames: 3 × 50 = 150; prefix IDs: 600.
  • User requests 7 s more → generate 7 × 50 × 4 = 1400 new steps.
  • Total output length 10 s → 500 frames, 2000 IDs.
  • At step 601, model sees fixed drum prefix + text c → must predict piano/jazz-compatible tokens, not restart drums from scratch unless prompt asks.
