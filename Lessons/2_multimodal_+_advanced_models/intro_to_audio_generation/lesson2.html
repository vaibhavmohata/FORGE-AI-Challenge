0. Music primer for complete beginners

Read once if you have never played an instrument. Everything below is referenced in gen-AI papers.

Pitch names and the piano keyboard

Western pitches use letters A B C D E F G, repeating in higher and lower registers. On a keyboard, moving right = higher pitch. Black keys are sharps/flats (e.g. C♯ between C and D).

MIDI note numbers

Computers label pitches with integers. Convention: Middle C = MIDI 60. Each +1 is one semitone (adjacent key, white or black). An octave = 12 semitones; frequency ≈ doubles per octave.

MIDI nNameRole
57A3Below middle C
60C4Middle C
64E4Major third above C4
69A4Concert tuning reference (440 Hz)
72C5C4 up one octave

Time, beats, velocity

  • Tempo (BPM) — beats per minute. At 120 BPM, one quarter-note beat = 0.5 s.
  • Duration — how long a note sounds (quarter, eighth, …).
  • Velocity (0–127) — MIDI’s proxy for “how hard you hit the key” → affects loudness and attack.
  • Chord — several pitches simultaneously. Unlike text (one token stream), music often has parallel events.

Quiz 1 — MIDI arithmetic

Q: Middle C is 60. What MIDI number is the C one octave higher? How many semitones between MIDI 60 and 67?

Show answer

One octave up: 60 + 12 = 72 (C5). 67 − 60 = 7 semitones (C→G is a perfect fifth).

1. Pitch → frequency — the MIDI formula

To synthesize a MIDI note as audio (as in our piano-roll demo), convert note number n to frequency in Hz:

f (Hz) = 440 × 2(n − 69) / 12

MIDI 69 = A4 = 440 Hz by definition. Each +12 adds one octave (×2 frequency).

Worked examples

A4 (n = 69): f = 440 × 2(69−69)/12 = 440 × 1 = 440.0 Hz

C4 (n = 60): exponent = (60−69)/12 = −9/12 = −0.75 → f = 440 × 2−0.75 ≈ 440 × 0.5946 ≈ 261.6 Hz

C5 (n = 72): f = 440 × 23/12 = 440 × 20.25 ≈ 523.3 Hz (exactly 2× C4)

2. MIDI as an event list — concrete 4-note melody

MIDI files are not audio. They are timestamped messages: NOTE_ON, NOTE_OFF, program change, tempo, etc. A Digital Audio Workstation (DAW) “plays” MIDI by sending those events to a synthesizer.

Example melody (one note per beat, 4 beats)

1E464329.6
2G467392.0
3C572523.3
t=0.00s NOTE_ON ch=0 pitch=60 vel=90 t=0.50s NOTE_OFF ch=0 pitch=60 t=0.50s NOTE_ON ch=0 pitch=64 vel=90 t=1.00s NOTE_OFF ch=0 pitch=64 t=1.00s NOTE_ON ch=0 pitch=67 vel=90 t=1.50s NOTE_OFF ch=0 pitch=67 t=1.50s NOTE_ON ch=0 pitch=72 vel=90 t=2.00s NOTE_OFF ch=0 pitch=72

8 messages, ~120 bytes on disk for this fragment — versus ~352,800 PCM samples for 2 s @ 44.1 kHz mono (705 KB).

Same melody as a piano-roll matrix

Quantize time into columns (here 4 steps). Rows = pitch classes in range. Cell value = off (0) or on (1); richer rolls store velocity 0–127 instead of binary.

Quiz 3 — Matrix shape

Q: A piano roll spans MIDI pitches 21–108 (88 keys) at 512 time steps with binary on/off. What is the matrix shape? How many entries if stored dense?

Show answer

Rows = 108 − 21 + 1 = 88. Shape = (88, 512). Dense entries = 88 × 512 = 45,056 (still tiny vs WAV).

3. Symbolic tokenization for language models (REMI-style)

Transformers want a 1-D token sequence. Raw piano-roll matrices are 2-D and sparse. REMI (Huang & Yang, 2020) and cousins flatten events into ordered tokens: [Bar, Position, Pitch, Duration, Velocity] repeated per note.

Walk-through — our 4-note melody in one bar

Assume 4/4 time, 4 positions per bar (quarter notes), velocity 90, each note duration = 1 position.

StepTokenMeaning
1Bar_0Start of bar 0
2Pos_0Beat position 0
3Pitch_60C4
4Dur_11 grid unit long
5Vel_90Loudness level
6Pos_1Beat position 1
7Pitch_64E4
8Dur_1…
9Vel_90…
… continues for G4 @ Pos_2, C5 @ Pos_3 …
token_sequence length ≈ 1 + 4 × 4 = 17 tokens (one Bar + 4 notes × 4 fields) vocab size ≈ bars + positions + 128 pitches + durations + 128 velocities (thousands, not millions)

Compared to Lesson 1: 2 s of WAV @ 44.1 kHz → 88,200 samples. Same melody as REMI → ~17 discrete tokens. That is why symbolic LMs (MuseNet-style, music transformers) start here — before tackling audio codecs in Lesson 3.

Quiz 4 — Token count

Q: A bar contains 8 eighth-notes, each encoded as Pos + Pitch + Dur + Vel after one Bar token. How many tokens?

Show answer

1 + 8 × 4 = 33 tokens.

4. Trade-offs with numbers — recipe vs record

Symbolic (MIDI / REMI)Raw audio (WAV PCM)
Typical size~2–50 KB for a pop song sketch~30 MB for 3 min stereo CD-quality
Ratio (rough)WAV often 1,000×–10,000× larger than MIDI for the same musical “content”
Edit key / tempoChange pitch or BPM fields; re-renderRequires source separation or re-record
RealismDepends on synthesizer / sample libraryCaptures room, breath, guitar squeak
Gen-AI fitDiscrete tokens → standard LMNeeds codec (Lesson 3) or spectrogram diffusion
DAW workflowProducers prefer MIDI for editing arrangementFinal mix exported to WAV/MP3
Numerical snapshot — same 4-note, 2 s phrase:
  • MIDI event list above: ~120 B
  • PCM mono 44.1 kHz × 2 s: 88,200 samples × 2 B ≈ 172 KB
  • Size ratio ≈ 172,000 / 120 ≈ 1,400×
Metaphor: MIDI is a recipe (ingredients + steps). WAV is a video of the finished dish — delicious, but you cannot easily swap salt for sugar after baking.

Quiz 5 — Engineering choice

Q: You are building a tool to transpose a melody to a different key and swap piano for strings. Start from MIDI or a studio WAV? Estimate file sizes for a 90 s sketch.

Show answer

MIDI — transpose = add semitones to pitch events; swap instrument = change program number. Size ~5–20 KB. WAV stereo 90 s ≈ 90 × 44,100 × 2 × 2 B ≈ 15.9 MB; editing timbre/key is painful without transcription.

6. Guided lab — Google Bach Doodle (Coconet / Magenta)

Live model: Google Doodle — Celebrating J.S. Bach · Technical background: Magenta Coconet (Huang et al., counterpoint-infilling CNN + Gibbs sampling; later Doodle interface).

What the model actually does

Coconet is trained on Bach chorales encoded as symbolic score tensors — not waveforms. Given some voices filled in, it infills missing voices harmonically in Bach style. The Doodle lets you enter a soprano melody; the model generates alto/tenor/bass note events conditioned on yours.

ComponentIn Bach Doodle
Condition (input you control)Your melody notes (pitch + timing on the staff/grid)
Generation target (model output)Harmony voices — the accompanying parts that fit Bach-like rules
RepresentationDiscrete pitch/time events (symbolic) — same family as MIDI
Not usedRaw PCM, spectrograms, or mel bins
  1. Compose 1–2 measures in the Doodle (4–8 notes is enough).
  2. Run harmonization. Listen: which parts were yours vs added?
  3. Change one melody note; regenerate. Note which harmony voices move — that is conditioning sensitivity.
  4. In your notebook, write explicitly:
    Condition = ___________________
    Generation target = ___________________
    Why symbolic, not WAV? ___________________
  5. Connect to REMI: the model’s internal state is closer to piano-roll tensors than to Lesson 1 spectrograms.

Quiz 6 — Bach Doodle mechanics

Q: Is Coconet generating waveform samples, mel spectrogram frames, or symbolic note events? What is the condition?

Show answer

Symbolic note events (multi-voice score). Condition = the user-provided melody (fixed voices); target = infilled harmony voices.

Quiz 7 — Compare paradigms

Q: Name one task MIDI handles better than WAV and one task WAV handles better than MIDI.

Show answer

MIDI better: transposition, tempo change, instrument swap. WAV better: capturing human vocal timbre, room reverb, acoustic imperfection.
