2. Inference pseudocode (codec + transformer)

# MusicGen-style (high level) text_ids = tokenize(user_prompt) # (L,) c = text_encoder(text_ids) # (L, d) audio_tokens = encode_prefix(user_wav) if given else [] while len(audio_tokens) < target_len: h = transformer(audio_tokens, condition=c) # causal logits = lm_head(h[-1]) # (V,) if guidance_scale > 1: logits_u = transformer(audio_tokens, condition=null) logits = logits_u + w * (logits - logits_u) audio_tokens.append(sample(logits, temp, top_p)) latents = codec_lookup(audio_tokens) # (F, D) wav = codec_decoder(latents) # (T,) export(wav, sr=32000)
  1. Text never becomes audio without passing through token prediction.
  2. Prefix tokens are copied verbatim (continuation).
  3. Decoder runs after ID sequence complete (streaming variants overlap).

3. Diffusion alternate path

  1. Encode text → c.
  2. Sample noise zT matching latent shape (time × freq bins).
  3. For t = T down to 1: zt−1 = denoise_step(zt, c, t).
  4. Vocoder / decoder → waveform.

8. Streaming & latency (product reality)

Apps rarely wait for all 2000 tokens before playback. Streaming variants:

  • Decode overlapping windows as tokens arrive (chunked codec decode).
  • Show UI progress per second generated (~50 frames/s × decode cost).
  • GPU batch size 1 on consumer hardware → AR serial loop dominates MusicGen latency.
Back-of-envelope: If each AR step ≈ 20 ms on a GPU, 2000 steps ≈ 40 s wall time (optimistic upper bound; real stacks use KV-cache and fused kernels to do better). Diffusion with 50 steps × 200 ms ≈ 10 s — different hardware profiles cross over.

10. Ethics case sketches

Case A — Style mimic: Prompt says “in the style of [living artist].” Model may interpolate training examples. Harm: market substitution; legal unsettled. Mitigation: avoid artist names; use generic descriptors; disclose AI.
Case B — Voice cover: Upload 30 s of a singer, “continue in same voice.” Maps to timbre conditioning. Harm: non-consensual imitation. Mitigation: ban uploads of third-party voices; consent forms; audible disclaimers.
Case C — Dataset provenance: Codec trained on licensed + scraped audio. Harm: collective creator uncompensated. Mitigation: opt-in licensing (industry in flux); prefer models with documented training.
Capstone ethics paragraph should name one concrete risk from above and one mitigation you would actually implement before publishing.

13. Diffusion inference checklist (usable without SDE math)

  1. Pick step count T (e.g. 50) — more steps often cleaner, slower.
  2. Encode prompt → condition vector (same encoders as AR systems).
  3. Sample initial noise zT with same shape as training latents.
  4. Loop t = T…1: update z using network prediction (noise or x0).
  5. Apply CFG by blending conditional and unconditional predictions each step.
  6. Feed final z through vocoder/decoder → waveform (L1 samples).

Image unit will name the prediction target and derive the update rule; here you only need the control flow to read papers and UIs.

16. Pseudocode — diffusion path (parallel to §2)

# Diffusion audio (high level — math deferred to image unit) c = text_encoder(tokenize(prompt)) z = randn(latent_shape) # noise at step T for t in reversed(range(1, T+1)): eps_cond = denoiser(z, t, condition=c) eps_uncond = denoiser(z, t, condition=null) eps = eps_uncond + w * (eps_cond - eps_uncond) # CFG z = scheduler_step(z, eps, t) # update rule taught in image unit waveform = vocoder(z) # (T,) samples

Compare to §2: AR loops over token indices; diffusion loops over continuous z. Both accept the same text condition c from Lesson 4.
